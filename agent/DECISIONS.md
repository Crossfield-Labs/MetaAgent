# 迁移决策文档

这份文档记录的是当前仓库已经沉淀下来的关键决策。目标不是复盘全部对话，而是把后续开发最容易误判的结论固定下来。

## 1. `MetaAgent` 不是空壳

结论：
- 当前仓库已经不是单纯架构模板
- 大部分主体代码、页面、服务、资源和模块已经迁入

意味着：
- 后续工作重点不是“从零搭骨架”
- 而是“继续稳定、清理、收敛”

## 2. 本地模型不是当前方向

结论：
- `mnn`、`llama` 已从主工程依赖中剔除
- 当前目标不保留本地模型主线

意味着：
- 后续不要再围绕本地模型补功能
- 如果出现相关残留，优先按移除方向处理

## 3. `terminal` 当前仍保留

结论：
- `terminal` 没有彻底移除
- 原因不是产品还想做“内置 Ubuntu”
- 而是当前部分自动化、执行环境、文件系统或工具链仍依赖 `terminal core`

意味着：
- 不要简单把 `terminal` 当成“可随便删的 Ubuntu 功能”
- 后续应逐步做的是“保留必要 core，收掉 Ubuntu 产品能力”

## 4. 当前阶段 Ubuntu 运行时通过固定 release 资产提供

结论：
- 为了恢复和 `Operit` 更接近的自动化行为，`MetaAgent` 仍保留 Ubuntu 运行时这条链
- 但运行时大包不进入 git 历史，而是固定从 `runtime-assets-v1` release 下载
- 固定地址是 `https://github.com/Crossfield-Labs/MetaAgent/releases/download/runtime-assets-v1/ubuntu-noble-aarch64-pd-v4.18.0.tar.xz`

意味着：
- 当前要先保证自动化能力恢复，不要在验证前再次裁掉这条链
- 后续如果有人找不到这个包，先去上面的 release 地址，不要再把大文件重新提交进仓库

## 5. 当前最主要的问题不是编译，而是自动化行为

结论：
- 目前仓库已经能本地编译、安装、演示
- 当前主风险在手机自动化正确性

典型表现：
- 打开 app 后早停
- 进入错误会话
- 把群聊当联系人
- 明明没输入成功却声称已完成

意味着：
- 后续优先级应放在提示词、代理决策、动作验证
- 不是优先继续做大规模模块迁移

## 6. 多步 App 内任务必须优先走 UI 子代理

结论：
- 像 QQ、微信、B 站这类“打开 app 后继续搜索、选择、输入、发送”的任务
- 当前明确要求优先走 `run_ui_subagent`

意味着：
- 不要随便降级到分享面板类工具
- 不要把“打开 app”当完成

## 7. QQ 分享式发送工具不是正确路径

结论：
- `daily_life.js` 中原来的 `qq_send_message` 路径只会拉起分享界面
- 它不能满足“给指定群聊/联系人发消息”的自动化目标

因此已经做出的决策：
- 在 `MetaAgent` 中不再把这条路径视为正确解法
- 相关任务应回到 UI 自动化链路

## 8. 当前自动化策略偏向比赛演示

结论：
- 这次迁移过程中，很多默认策略已经偏向“演示优先”
- 例如权限策略、弹窗放行策略、自动化收紧策略

意味着：
- 某些实现不是长期产品化的最佳设计
- 它们是为了让当前比赛环境里更容易跑通

补充：
- 现在已经开始把自动化关键文件回退到 `Operit` 基线
- 后续优先级高于继续新增演示专用兜底

## 9. QQ 指定群聊发消息仍未彻底解决

结论：
- 这条链已经做过多轮修正，但当前仍存在目标识别不稳、把群聊当个人、进入错误会话后提前停下的问题
- 它已经不是“只会打开 QQ”或“单纯走分享面板”的早期问题，而是更具体的界面判断和执行验证问题

意味着：
- 不要把这条能力视为已完成
- 后续如果继续修，优先检查 `PhoneAgent`、`SystemPromptConfig`、`SystemToolPromptsInternal`、`DebuggerUITools`

## 10. 现在应以补齐后的 `Operit` 作为对照基线

结论：
- 之前本地 `Operit` 不是完整 checkout，多个 submodule 缺失
- 现在子模块已经补齐，后续所有“和原项目一致吗”的判断都应以补齐后的仓库为准

意味着：
- 不要再基于之前那个缺子模块的 `Operit` 下结论
- 后续回退和对比要以完整基线为准

## 11. GitHub Release 可以直接上传本地 APK

结论：
- 当前发布不要求必须走 GitHub 构建产物
- 直接上传本地 `app-debug.apk` 就可以

意味着：
- 发布时不要被 CI 绑定住
- 先保证本地构建和安装正确

## 12. 文档目标不是替代全部对话，而是提供接手入口

结论：
- `agent/` 目录的目标不是保存每一句历史对话
- 而是让后来的人快速继续做事

意味着：
- 文档要记录关键结论、当前状态、模块定位、开发规则
- 不需要复述所有聊天过程
