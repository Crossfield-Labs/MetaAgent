# 学模块开发阶段记录（最小可演示版）

更新时间：2026-03-27

## 阶段1：课程空间（课程导入 + 列表 + 详情 + 课程问答入口）

### 本阶段完成内容
- 新增可持久化课程数据存储（本地 SharedPreferences + JSON）。
- 课程空间页支持：
  - 查看课程列表
  - 分类筛选
  - 导入课程（弹窗输入）
- 导入后课程会出现在列表，并可点击进入课程详情页。
- 新增课程详情页，展示简介、重点、进度、章节/资料统计。
- 课程详情页新增“进入 AI 对话”按钮，直接跳转现有 AIChat 页。

### 本阶段测试步骤
1. 打开 App，进入底部 `课程`。
2. 点击 `导入课程`，输入课程名并确认。
3. 验证：新课程出现在列表顶部。
4. 点击课程卡片，进入 `课程详情`。
5. 点击 `进入 AI 对话`，进入现有 AI 聊天页，并自动新建课程会话。

### 本阶段演示流程（录屏建议）
1. 先展示默认 3 门课程。
2. 演示导入一门课程。
3. 展示导入后列表即时更新。
4. 点进详情页展示“课程重点”。
5. 点击按钮进入现有 AI 对话页，展示左上标题切到“课程问答”。

## 阶段2：一键整理（任务新增 + 列表 + 详情 + 异步进度）

### 本阶段完成内容
- 任务中心页支持：
  - 新建任务
  - 状态筛选（全部/执行中/待执行/已完成）
  - 统计卡片（总任务、执行中、已完成、待执行）

  - 当前状态
  - 当前进度
  - 执行步骤说明
  - 创建/更新时间
  - 完成后结果输出

## 实现说明（最小可演示策略）
- 当前版本以“可演示、可走通流程”为目标。
- 对话与任务执行结果为可控 Mock/规则生成，不依赖真实向量库或真实异步任务后端。
- 后续可平滑替换为真实后端：
  - 课程导入 -> 服务端课程库
  - 任务执行 -> Agent 编排/执行引擎
  - 问答 -> 向量检索 + LLM

## 阶段9：一键整理执行流升级（可切换课程 + 入队待执行 + 跨端执行独立会话 + 任务附件）

  - `StudyTask` 新增附件字段并兼容历史数据。

## 阶段10：任务完成通知 + 统计页 See all 详细分析

### 本阶段完成内容
- 顶部通知（任务中心）完善：
  - 新增任务通知中心（持久化保存）。
  - 当任务状态从“非完成”变为“已完成”时，自动生成一条通知。
  - 通知支持未读/已读状态，顶部铃铛显示未读角标。
  - 点击铃铛可查看通知列表；点击通知可直接跳转对应任务详情。

  - 新增通知读写、标记已读能力。
  - 在任务状态更新逻辑中自动检测完成事件并推送通知。
- 统计卡 `See all` 落地为详细统计弹窗：
  - 指标卡：任务总数、完成率、平均进度、平均耗时。
  - 图表1：任务状态环图（待执行/执行中/已完成/失败）。
  - 图表2：课程任务占比柱状图（Top 6）。
  - 图表3：时长分层与进度分层堆叠条。
  - 列表：最近完成任务（含时间）。
